# My Project

## Description

This is a simple Node.js project demonstrating file handling, REST API, and modular structure.

## Features

* File handling using fs module
* REST API (GET, POST)
* Modular code structure

## Installation

```bash
npm install
```

## Run Project

```bash
node app.js
```

## API Endpoints

* GET /users
* POST /users
